# 가사 프롬프터 (Lyrics Prompter)

듀얼 모니터용 가사 프롬프터 데스크톱 앱입니다. 실행하면 창이 두 개 뜹니다.

- **콘솔 창** (주 모니터): 곡 추가/검색/수정, 클릭 한 번으로 프롬프터에 가사 전송
- **프롬프터 창** (보조 모니터): 가사만 크게 표시하는 전체화면 창. 모니터가 두 개면 자동으로 보조 모니터에 전체화면으로 배치됩니다.

## 실행 방법

```bash
cd lyrics-prompter
npm install
npm start
```

## 사용법

1. 콘솔 왼쪽 목록에서 **+ 새 곡**을 눌러 제목과 가사를 입력하고 **저장**합니다.
2. 목록에서 곡을 클릭해 선택한 뒤 **▶ 프롬프터로 보내기**를 누르면 (또는 목록에서 곡을 더블클릭하면) 보조 모니터의 프롬프터 창에 바로 표시됩니다.
3. 콘솔 하단 바에서 **글자 크기**를 조절하고, **지우기**로 프롬프터 화면을 비울 수 있습니다.
4. 프롬프터 창에서는 `F11`로 전체화면을 켜고 끌 수 있고, `↑`/`↓`(또는 `Page Up`/`Page Down`)로 화면을 스크롤할 수 있습니다.

## 모니터 구성

- 모니터가 2개 연결된 상태에서 실행하면 콘솔은 주 모니터, 프롬프터는 보조 모니터에 자동으로 전체화면 배치됩니다.
- 모니터가 1개뿐이면 프롬프터 창이 일반 창(테두리 있음)으로 뜹니다. 이후 모니터를 추가로 연결하면 앱을 재시작해야 자동 배치가 적용됩니다.

## 데이터 저장

곡 목록은 OS의 앱 데이터 폴더(`userData/songs.json`)에 로컬로 저장됩니다. 별도 서버나 인터넷 연결이 필요 없습니다.

## 배포용 패키징 (선택)

지금은 `npm start`로 소스에서 바로 실행하는 개발용 구성입니다. 나중에 `.exe`/`.dmg` 설치 파일로 배포하려면 [`electron-builder`](https://www.electron.build/) 추가를 고려하세요.
