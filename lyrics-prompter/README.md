# 가사 프롬프터 (Lyrics Prompter)

설치나 서버 없이 **HTML 파일 두 개를 더블클릭**하면 바로 실행되는 듀얼 모니터
가사 프롬프터입니다. Node.js, npm, Electron 전부 필요 없습니다.

- `console.html` — 콘솔 창: 곡 추가/검색/수정, 클릭 한 번으로 프롬프터에 가사 전송
- `prompter.html` — 프롬프터 창: 가사만 크게 표시. 콘솔에서 "프롬프터 창 열기"를
  누르면 이 파일이 새 창으로 자동으로 열립니다 (따로 실행할 필요 없음).

## 실행 방법

1. `console.html`을 더블클릭해서 브라우저로 엽니다 (Chrome 또는 Edge 권장).
2. **+ 새 곡**으로 제목/가수를 입력합니다. **가사 자동 검색**을 누르면 인터넷에서
   가사를 찾아 채워줍니다 (아래 "가사 자동 검색" 참고). 못 찾으면 직접 붙여넣으면
   됩니다. 이후 **저장**을 누릅니다.
3. **프롬프터 창 열기**를 눌러 프롬프터용 창을 띄우고, 그 창을 보조 모니터로
   옮깁니다 (아래 "듀얼 모니터 자동 배치" 참고).
4. 곡을 선택 후 **▶ 프롬프터로 보내기** (또는 목록에서 더블클릭)를 누르면
   프롬프터 창에 즉시 표시됩니다.
5. 글자 크기 조절, 지우기 버튼은 콘솔 하단 바에 있습니다.
6. 프롬프터 창에서 `F11`로 전체화면 전환, `↑`/`↓`(또는 `Page Up`/`Page Down`)로
   스크롤할 수 있습니다.

## 가사 자동 검색

곡 제목과 가수를 입력하고 **가사 자동 검색**을 누르면 무료 공개 가사 API
([lyrics.ovh](https://lyrics.ovh))에서 가사를 찾아 자동으로 채워줍니다.
인터넷 연결이 필요하고, 아래 한계가 있습니다.

- **국내 가요(K-pop)는 데이터베이스가 부실해서 못 찾는 경우가 많습니다.**
  주로 해외 곡 위주로 검색이 잘 됩니다.
- 찾지 못하면 "가사를 찾지 못했어요" 메시지가 뜨고, 그 아래 칸에 직접
  붙여넣거나 입력하면 됩니다.
- 무료 공개 API라 서비스 상태나 정책이 바뀌면 동작하지 않을 수도 있습니다.

## 음원 파일만 넣어도 제목/가수/가사가 자동으로

**음원 파일 선택**으로 mp3를 첨부하면, 파일 안에 들어있는 태그(ID3 태그 —
보통 음악 플레이어에 곡 제목/가수가 표시되는 바로 그 정보)를 읽어서
제목/가수 칸을 자동으로 채워줍니다. 그리고 제목/가수가 채워지고 가사 칸이
비어있으면 **가사 자동 검색**도 곧바로 실행됩니다. 즉, 태그가 있는 mp3라면
파일만 넣어도 제목·가수·가사까지 한 번에 채워질 수 있습니다.

- 이미 제목/가수를 직접 입력해뒀다면 태그로 덮어쓰지 않습니다.
- 태그가 없는 mp3(예: 태그 없이 변환된 파일)는 자동으로 채워지는 게 없을 뿐,
  파일 첨부 자체는 정상적으로 됩니다 — 이 경우 제목/가수를 직접 입력해주세요.
- ID3v2(v2.3, v2.4) 태그만 지원합니다. 아주 오래된 형식(ID3v1, ID3v2.2)은
  인식하지 못할 수 있습니다.
- 국내 가요는 위 "가사 자동 검색" 한계(lyrics.ovh 커버리지) 때문에 자동으로
  못 찾을 수 있습니다 — 그럴 땐 직접 붙여넣으면 됩니다.

## 노래방처럼 자동 진행 (싱크 가사 + 음원 파일)

곡 편집 화면의 "노래방처럼 자동 진행" 칸에 **싱크 가사(LRC)** 와 **음원 파일**을
모두 넣으면, 프롬프터 창에서 노래방처럼 현재 부르는 줄이 자동으로 하이라이트되고
다음 줄이 자동으로 올라옵니다.

**중요**: 이 동기화는 **이 앱이 직접 재생하는 소리**를 기준으로 동작합니다.
공연장에서 음악을 다른 장비(별도 재생기, DJ 콘솔 등)로 튼다면 이 기능은
의미가 없습니다 — 이 앱의 재생 버튼으로 튼 소리가 실제로 스피커/음향 시스템에
연결되어 있어야 싱크가 맞습니다.

설정 방법:
1. **싱크 가사 자동 검색**을 누르면 [LRCLIB](https://lrclib.net)에서
   타임스탬프가 있는 가사를 찾아줍니다. 못 찾으면 `.lrc` 파일을 구해서 그 내용을
   직접 붙여넣어도 됩니다 (형식: `[00:12.34]가사 한 줄`). 그래도 안 되면 아래
   "탭으로 싱크 찍기"를 쓰세요.
2. **음원 파일 선택**으로 해당 곡의 오디오 파일(mp3 등)을 첨부합니다.
   이 파일은 브라우저 메모리에만 유지되고 저장되지 않으므로, **새로고침하면
   다시 선택**해야 합니다.
3. 곡을 프롬프터로 보내면 콘솔 하단에 재생 컨트롤(재생/일시정지/탐색바)이
   나타납니다. 이 버튼으로 음악을 재생하면 프롬프터 화면이 자동으로 따라갑니다.
4. 싱크 가사나 음원 중 하나라도 없으면 기존처럼 전체 가사가 고정으로 표시되고
   `↑`/`↓`로 수동 스크롤합니다 — 아무것도 깨지지 않습니다.

국내 가요는 LRCLIB에서도 못 찾을 수 있습니다 (멜론/지니/벅스 모두 가사를
공식 API로 제공하지 않아서, 자동 검색으로는 한계가 있습니다). 그럴 땐 아래
"탭으로 싱크 찍기"로 직접 만드는 게 가장 확실합니다.

> **유튜브 URL 재생(임베드)은 지원하지 않습니다.** 시도해봤는데, 유튜브가 임베드
> 플레이어에 HTTP 출처(Referer) 헤더를 요구하기 시작해서 `file://`로 직접 여는
> 이 앱 구조로는 재생이 막힙니다 (오류 153). 대신 유튜브를 **다른 탭에서 그냥
> 평소처럼 재생**하면서 쓸 수 있는 "라이브 모드"를 아래에 만들었습니다.

## 라이브(수동) 모드 — 유튜브 MR 등 음원 파일이 없을 때

음원 파일이 없거나(유튜브에서 받은 MR 등), 있는 파일이 실제 연주 버전과 달라서
자동 싱크를 믿기 어려운 경우를 위한 모드입니다. 앱이 음원을 재생하지 않고,
**오퍼레이터가 실시간으로 다음 줄을 눌러 진행**합니다. 그래서 음원을 어디서
어떻게 틀든(유튜브를 다른 탭/창에서 그냥 재생, 실제 라이브 연주 등) 상관없습니다.

사용법:
1. 가사를 한 줄에 한 줄씩 입력합니다 (음원 파일이나 싱크 가사는 필요 없음).
2. **🎤 라이브 모드로 보내기**를 누릅니다. 프롬프터 창이 열리고, 첫 줄이
   아직 표시되지 않은 대기 상태로 시작합니다.
3. 유튜브(또는 다른 어떤 소스든)로 MR을 재생하면서, 실제로 그 가사가 나오는
   순간 콘솔에서 **다음 줄 ▶** (또는 스페이스바)을 누르세요. 프롬프터 화면에
   그 줄이 바로 뜹니다. 실수하면 **◀ 이전 줄**(또는 백스페이스)로 되돌릴 수
   있습니다.
4. 콘솔 화면에 이전/현재/다음 줄이 미리 보여서, 프롬프터 화면(관객/가수 쪽
   모니터)을 직접 보지 않아도 다음에 뭐가 나올지 알 수 있습니다.
5. 끝나면 **라이브 모드 종료**를 누르세요.

이 모드는 정확도가 전적으로 오퍼레이터의 타이밍에 달려있지만, 음원 파일·싱크
가사·유튜브 임베드 같은 조건이 전혀 필요 없어서 **어떤 상황에서도 항상 쓸 수
있는 가장 확실한 방법**입니다.

## 탭으로 싱크 찍기 (국내 가요 등 자동 검색이 안 될 때)

싱크 가사를 API로 못 찾아도, 직접 만들 수 있는 도구가 있습니다. 외부
서비스에 전혀 의존하지 않아서 **어떤 곡이든 100% 가능**합니다.

1. 먼저 **가사**(일반 텍스트, 한 줄에 한 줄씩)와 **음원 파일**을 곡에
   준비해두세요 (음원은 "음원 파일 선택"으로 첨부).
2. **탭으로 싱크 찍기** 버튼을 누르면 창이 뜹니다. 음원을 재생하면서,
   화면 가운데 굵게 표시된 가사 줄이 실제로 나오는 순간 **스페이스바**
   (또는 TAP 버튼)를 누르세요. 누를 때마다 다음 줄로 자동으로 넘어갑니다.
   - 박자를 맞추기 어려우면 우측 상단에서 0.75배속/0.5배속으로 느리게
     재생할 수 있습니다.
   - 잘못 눌렀다면 **되돌리기**(또는 백스페이스 키)로 마지막 탭을 취소하고,
     **처음부터**로 전체를 리셋할 수 있습니다.
3. 모든 줄을 다 찍으면 **LRC 만들기**를 눌러 싱크 가사 칸에 자동으로
   채워줍니다. 내용을 확인하고 **저장**을 누르면 끝입니다.

한 곡당 처음에 몇 분 정도 들으면서 탭해줘야 하지만, 한 번 만들어두면
그 다음부터는 계속 재사용됩니다.

## 듀얼 모니터 자동 배치

**Chrome 또는 Edge**에서는 "프롬프터 창 열기"를 누를 때 화면 배치 권한을
한 번 물어보고, 허용하면 프롬프터 창이 보조 모니터 위치에 자동으로 뜹니다.
그 외 브라우저이거나 권한을 거부한 경우 창이 기본 위치에 뜨니, 수동으로
보조 모니터로 드래그한 뒤 `F11`로 전체화면 전환하면 됩니다.

## 데이터 저장

곡 목록은 `console.html`을 연 브라우저의 로컬 저장소(localStorage)에
저장됩니다. 같은 브라우저에서 다시 `console.html`을 열면 그대로 남아있습니다.
(단, 파일을 다른 폴더로 옮기거나 다른 브라우저/PC에서 열면 새로 시작됩니다.)

## 주의

`console.html`과 `prompter.html`은 같은 폴더에 함께 있어야 합니다
(콘솔이 "프롬프터 창 열기"를 누르면 같은 폴더의 `prompter.html`을 엽니다).
