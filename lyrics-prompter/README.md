# 가사 프롬프터 (Lyrics Prompter)

듀얼 모니터용 가사 프롬프터입니다. `node server.js` 한 줄(또는 `run.bat`
더블클릭)로 실행되는 초경량 로컬 웹앱이고, `npm install`이나 Electron 같은
설치 과정은 필요 없습니다.

- `public/console.html` — 콘솔 창: 곡 추가/검색/수정, 클릭 한 번으로 프롬프터에 가사 전송
- `public/prompter.html` — 프롬프터 창: 가사만 크게 표시. 콘솔에서 "프롬프터 창 열기"를
  누르면 자동으로 새 창으로 열립니다.
- `server.js` — Node 내장 모듈만 쓰는 정적 파일 서버 (외부 패키지 없음)

## 왜 서버가 필요한가요?

전에는 `console.html`을 그냥 더블클릭(`file://`)해서 열 수 있었는데,
**유튜브 임베드 재생**을 붙이면서 문제가 생겼습니다. 유튜브가 임베드 플레이어에
HTTP Referer(출처) 헤더를 요구하는데, `file://`로 연 페이지는 애초에 HTTP
출처가 없어서 유튜브 쪽에서 "오류 153(설정 오류)"으로 재생을 막습니다. 이건
`referrerpolicy` 속성 같은 걸로 고칠 수 없는, `file://`의 근본적인 한계입니다.
그래서 `http://localhost`로 여는 아주 가벼운 로컬 서버를 다시 넣었습니다.

## 실행 방법

### Windows
`run.bat` 더블클릭 → 서버 창이 뜨고, 잠시 후 브라우저가 자동으로
콘솔 페이지(`http://localhost:5500`)를 엽니다.

### macOS / Linux
```bash
./run.sh
```

### 수동 실행 (모든 OS 공통)
```bash
cd lyrics-prompter
node server.js
```
그다음 브라우저에서 `http://localhost:5500`을 여세요.

> Node.js가 없다면 [nodejs.org](https://nodejs.org)에서 LTS 버전을 먼저 설치하세요.

> 유튜브 기능을 안 쓰고 음원 파일만 쓸 거라면, `public/console.html`을
> `file://`로 직접 더블클릭해서 열어도 나머지 기능은 다 똑같이 동작합니다.

## 사용법

1. 콘솔 왼쪽 목록에서 **+ 새 곡**을 눌러 제목/가수를 입력합니다.
   **가사 자동 검색**을 누르면 인터넷에서 가사를 찾아 채워줍니다 (아래
   "가사 자동 검색" 참고). 못 찾으면 직접 붙여넣으면 됩니다. **저장**을 누릅니다.
2. **프롬프터 창 열기**를 눌러 프롬프터용 창을 띄우고, 보조 모니터로
   옮깁니다 (아래 "듀얼 모니터 자동 배치" 참고).
3. 곡을 선택 후 **▶ 프롬프터로 보내기** (또는 목록에서 더블클릭)를 누르면
   프롬프터 창에 즉시 표시됩니다.
4. 글자 크기 조절, 지우기 버튼은 콘솔 하단 바에 있습니다.
5. 프롬프터 창에서 `F11`로 전체화면 전환, `↑`/`↓`(또는 `Page Up`/`Page Down`)로
   스크롤할 수 있습니다.

## 가사 자동 검색

곡 제목과 가수를 입력하고 **가사 자동 검색**을 누르면 무료 공개 가사 API
([lyrics.ovh](https://lyrics.ovh))에서 가사를 찾아 자동으로 채워줍니다.
인터넷 연결이 필요하고, 아래 한계가 있습니다.

- **국내 가요(K-pop)는 데이터베이스가 부실해서 못 찾는 경우가 많습니다.**
  주로 해외 곡 위주로 검색이 잘 됩니다.
- 찾지 못하면 "가사를 찾지 못했어요" 메시지가 뜨고, 그 아래 칸에 직접
  붙여넣거나 입력하면 됩니다.
- 무료 공개 API라 서비스 상태나 정책이 바뀌면 동작하지 않을 수도 있습니다.

## 노래방처럼 자동 진행 (싱크 가사 + 음원)

곡 편집 화면의 "노래방처럼 자동 진행" 칸에 **싱크 가사(LRC)** 와 **음원**을
모두 넣으면, 프롬프터 창에서 노래방처럼 현재 부르는 줄이 자동으로 하이라이트되고
다음 줄이 자동으로 올라옵니다.

**중요**: 이 동기화는 **이 앱이 직접 재생하는 소리**를 기준으로 동작합니다.
공연장에서 음악을 다른 장비(별도 재생기, DJ 콘솔 등)로 튼다면 이 기능은
의미가 없습니다 — 이 앱의 재생 버튼으로 튼 소리가 실제로 스피커/음향 시스템에
연결되어 있어야 싱크가 맞습니다.

설정 방법:
1. **싱크 가사 자동 검색**을 누르면 [LRCLIB](https://lrclib.net)에서
   타임스탬프가 있는 가사를 찾아줍니다. 못 찾으면 `.lrc` 파일을 구해서 그 내용을
   직접 붙여넣어도 됩니다 (형식: `[00:12.34]가사 한 줄`). 그래도 안 되면 아래
   "탭으로 싱크 찍기"를 쓰세요.
2. 음원은 두 가지 방법 중 하나로 넣을 수 있습니다.
   - **음원 파일 선택**으로 오디오 파일(mp3 등)을 첨부. 브라우저 메모리에만
     유지되므로 **새로고침하면 다시 선택**해야 합니다.
   - 또는 **유튜브 URL** 칸에 링크를 붙여넣기 (`watch?v=`, `youtu.be/`, `shorts/`
     형식 지원). 곡과 함께 저장되어 새로고침해도 남아있습니다. 음원 파일을
     첨부했다면 파일이 우선 사용되고, 파일이 없을 때만 유튜브 링크가 쓰입니다.
3. 곡을 프롬프터로 보내면 콘솔 하단에 재생 컨트롤이 나타납니다
   (파일이면 재생바, 유튜브면 영상 플레이어). 여기서 재생하면 프롬프터 화면이
   자동으로 따라갑니다.
4. 싱크 가사나 음원 중 하나라도 없으면 기존처럼 전체 가사가 고정으로 표시되고
   `↑`/`↓`로 수동 스크롤합니다 — 아무것도 깨지지 않습니다.

**유튜브 사용 시 참고**:
- 반드시 `node server.js`(또는 `run.bat`/`run.sh`)로 실행해서
  `http://localhost`로 열어야 합니다. `file://`로 직접 열면 유튜브 재생이
  막힙니다 (위 "왜 서버가 필요한가요?" 참고).
- 콘솔 화면에 작은 영상이 함께 보입니다 (프롬프터 창에는 가사만 나오고
  영상은 안 보입니다).
- 일부 영상은 업로더가 "다른 사이트에 퍼가기(임베드)"를 막아둬서 재생이 안 될
  수 있습니다 (오류 메시지에 "임베드를 막아놨어요"로 표시됩니다). 그럴 땐
  음원 파일을 직접 첨부하세요.

국내 가요는 LRCLIB에서도 못 찾을 수 있습니다 (멜론/지니/벅스 모두 가사를
공식 API로 제공하지 않아서, 자동 검색으로는 한계가 있습니다). 그럴 땐 아래
"탭으로 싱크 찍기"로 직접 만드는 게 가장 확실합니다.

## 탭으로 싱크 찍기 (국내 가요 등 자동 검색이 안 될 때)

싱크 가사를 API로 못 찾아도, 직접 만들 수 있는 도구가 있습니다. 외부
서비스에 전혀 의존하지 않아서 **어떤 곡이든 100% 가능**합니다.

1. 먼저 **가사**(일반 텍스트, 한 줄에 한 줄씩)와 **음원**(파일 첨부 또는
   유튜브 URL)을 곡에 준비해두세요.
2. **탭으로 싱크 찍기** 버튼을 누르면 창이 뜹니다. 음원을 재생하면서,
   화면 가운데 굵게 표시된 가사 줄이 실제로 나오는 순간 **스페이스바**
   (또는 TAP 버튼)를 누르세요. 누를 때마다 다음 줄로 자동으로 넘어갑니다.
   - 박자를 맞추기 어려우면 우측 상단에서 0.75배속/0.5배속으로 느리게
     재생할 수 있습니다.
   - 잘못 눌렀다면 **되돌리기**(또는 백스페이스 키)로 마지막 탭을 취소하고,
     **처음부터**로 전체를 리셋할 수 있습니다.
3. 모든 줄을 다 찍으면 **LRC 만들기**를 눌러 싱크 가사 칸에 자동으로
   채워줍니다. 내용을 확인하고 **저장**을 누르면 끝입니다.

한 곡당 처음에 몇 분 정도 들으면서 탭해줘야 하지만, 한 번 만들어두면
그 다음부터는 계속 재사용됩니다.

## 듀얼 모니터 자동 배치

**Chrome 또는 Edge**에서는 "프롬프터 창 열기"를 누를 때 화면 배치 권한을
한 번 물어보고, 허용하면 프롬프터 창이 보조 모니터 위치에 자동으로 뜹니다.
그 외 브라우저이거나 권한을 거부한 경우 창이 기본 위치에 뜨니, 수동으로
보조 모니터로 드래그한 뒤 `F11`로 전체화면 전환하면 됩니다.

## 데이터 저장

곡 목록은 브라우저의 로컬 저장소(localStorage)에 저장됩니다. 같은
브라우저에서 다시 열면 그대로 남아있습니다.
