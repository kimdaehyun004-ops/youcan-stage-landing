# 가사 프롬프터 (Lyrics Prompter) - 웹 버전

브라우저 창 두 개로 동작하는 듀얼 모니터 가사 프롬프터입니다. 설치 과정 없이
Node.js만 있으면 바로 실행됩니다 (`npm install` 불필요, Electron 등 외부
패키지 없음).

- **콘솔 창** (`console.html`): 곡 추가/검색/수정, 클릭 한 번으로 프롬프터에 가사 전송
- **프롬프터 창** (`prompter.html`): 가사만 크게 표시하는 창. "프롬프터 창 열기"를 누르면
  가능한 경우 자동으로 보조 모니터 위치에 뜹니다.

## 실행 방법

### Windows
`run.bat` 파일을 더블클릭하세요. 서버 창이 뜨고, 잠시 후 브라우저가 자동으로
콘솔 페이지(`http://localhost:5500`)를 엽니다.

### macOS / Linux
```bash
./run.sh
```

### 수동 실행 (모든 OS 공통)
```bash
cd lyrics-prompter
node server.js
```
그다음 브라우저에서 `http://localhost:5500` 을 여세요.

> Node.js가 없다면 [nodejs.org](https://nodejs.org)에서 LTS 버전을 먼저 설치하세요.

## 사용법

1. 콘솔 왼쪽 목록에서 **+ 새 곡**을 눌러 제목과 가사를 입력하고 **저장**합니다.
2. **프롬프터 창 열기**를 눌러 프롬프터용 창을 엽니다. 이 창을 보조 모니터로
   옮겨주세요 (아래 "듀얼 모니터 자동 배치" 참고).
3. 곡을 선택한 뒤 **▶ 프롬프터로 보내기**를 누르면 (또는 목록에서 곡을 더블클릭하면)
   프롬프터 창에 즉시 표시됩니다.
4. 콘솔 하단 바에서 **글자 크기**를 조절하고, **지우기**로 프롬프터 화면을 비울 수 있습니다.
5. 프롬프터 창에서 `F11`을 누르면 브라우저 자체 전체화면으로 전환됩니다.
   `↑`/`↓`(또는 `Page Up`/`Page Down`)로 화면을 스크롤할 수 있습니다.

## 듀얼 모니터 자동 배치

**Chrome 또는 Edge** 브라우저를 사용하면 "프롬프터 창 열기"를 누를 때 화면
배치 권한을 한 번 물어보고, 허용하면 프롬프터 창이 보조 모니터 위치에 자동으로
뜹니다 (Window Management API). Firefox/Safari 등 이 기능을 지원하지 않는
브라우저에서는 창이 기본 위치에 뜨니 수동으로 보조 모니터로 드래그한 뒤 `F11`로
전체화면 전환하면 됩니다.

콘솔과 프롬프터 창은 반드시 **같은 브라우저**의 **같은 주소(`http://localhost:5500`)**
에서 열려야 실시간으로 연동됩니다 (다른 브라우저나 시크릿 창끼리는 연동되지 않습니다).

## 데이터 저장

곡 목록은 브라우저의 `localStorage`에 저장됩니다. 서버는 파일만 전달할 뿐
데이터를 따로 보관하지 않으므로, 브라우저(같은 프로필)를 바꾸면 곡 목록도
새로 시작됩니다.
