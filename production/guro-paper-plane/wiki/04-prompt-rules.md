# 04. Seedance 프롬프트 규칙

## 구조 (hfgate build가 자동으로 조립합니다)
```
STYLE 고정 문구    ← 원테이크, 컷 금지, 짐벌 카메라
PLANE 고정 문구    ← 비대칭 다트형, 기수 방향 비행, 연속 경로
LIGHT 고정 문구
장소 고정 문구     ← SEQ에서 '보이는' 장소 전부
(연장이면) 앞 영상의 마지막 프레임에서 그대로 이어짐
START STATE: …    ← 앞 SEQ의 FINAL FRAME과 같은 문장 (L8)
0-2s: … / 2-4s: … ← 빈틈 없이 0초부터 duration까지 (L6)
FINAL FRAME: …
Audio: 현장음만
Negative: 공통 금지어 + SEQ별 금지어
```

## 규칙
1. **고정 문구는 손대지 않습니다.**
   - 바꿀 일이 있으면 bible.json을 수정합니다. 그러면 모든 SEQ에 똑같이 적용됩니다.
   - bible을 바꿨다면 accepted 상태인 SEQ와 문구가 어긋나는지도 검토합니다.
2. **카메라는 비행기 뒤나 옆에서 따라갑니다.**
   - 정면 마주 보기, 역주행, swing·pivot·whip은 금지입니다(E2·E5, L13).
   - 방향을 바꿀 때는 3초 이상에 걸쳐 완만한 곡선으로 지시합니다.
3. **끝 이미지(end_image)는 쓰지 않습니다(E4, L3).** 마지막 상태는 글(FINAL FRAME)로만 씁니다.
4. **보이는 장소는 전부 레퍼런스로 첨부합니다(E6, L2).** 문틈이나 창밖으로 보이는 장소도 포함합니다.
5. **좌우 지시는 프레임으로 확인한 경우에만 씁니다(R2).** 확인하지 않았다면 "같은 방향으로 계속"이라고 씁니다.
6. **긍정문에 금지어를 쓰지 않습니다(L5).**
   - 금지어 예: hand, launch, throw, firework, cheer, pointing at, whistle, logo, music
   - 부정문("no ...") 안에서는 쓸 수 있습니다.
   - 꼭 필요하면 spec의 `allow_terms`에 이유를 적습니다. 예: SEQ2 오디오의 "wind whistle"은 바람 소리라서 허용했습니다.
7. **멀쩡한 문장은 한 글자도 바꾸지 않습니다(L9).**
   - 사용자가 문제 삼지 않은 구간과 오디오는 이전 버전 문장을 그대로 복사합니다.
8. **실패한 프롬프트를 그대로 다시 보내지 않습니다.** 재시도할 때는 원인 가설과 바꾼 점을 spec에 기록합니다.

## lint 규칙표
| 규칙 | 검사 내용 | 근거 |
|---|---|---|
| L1 | 고정 문구가 프롬프트에 그대로 들어 있는가 | E2, E6 |
| L2 | bible 기준으로 그 SEQ에서 보이는 장소의 레퍼런스가 모두 첨부됐는가 | E6 |
| L3 | end_image가 없는가 | E4 |
| L4 | 연장의 앞 SEQ가 accepted이고 바로 앞 순서인가 | E7 |
| L5 | 긍정문에 금지어가 없는가 | E1, E12, D1~D6 |
| L6 | 구간이 0초부터 duration까지 빈틈과 겹침 없이 이어지는가 | — |
| L7 | 모델·해상도·프리셋 거절값이 맞는가 | E8 |
| L8 | START STATE가 앞 SEQ의 FINAL FRAME과 같은가 | E7, R2 |
| L9 | 이전 버전과 달라진 항목이 allowed_changes 안에 있는가 + 사용자 말 기록 | 사용자 원칙 |
| L10 | 프롬프트 길이(3,200자 초과 시 경고), 첨부 개수 | R9 |
| L11 | 첨부한 미디어 ID가 등록된 것인가 | E9 |
| L12 | 비용 ≤ 잔액 − 예비. 남은 계획까지 합산해 경고 | E14 |
| L13 | 컷을 유발하는 카메라 지시(swing, pivot, backward, facing 등)나 2초 미만의 빠른 이동이 없는가 | E5 |

## 검증
- 이 규칙을 과거 요청에 적용해 봤습니다. 실제로 컷이 났던 지시문이 모두 L13에 걸렸습니다.
  - SEQ1 v1: "swings around"
  - SEQ2 v1: "pivots", "moves backward facing", "swings quickly"
- 컷이 없었던 SEQ3 v1과 SEQ1 v3는 L13을 통과했습니다.
