### A안을 권장하는 이유
- **사실:**
  - SEQ3 v1의 마지막 장면은 이미 "태양을 향해 오르는 작은 비행기"였습니다(SEQ3.v1 FINAL FRAME).
  - SEQ4의 핵심인 눈부심, 화이트아웃, 타이틀 공간은 실사 동작이 아니라 빛 효과입니다.
- **추론:** 위 두 사실을 보면, SEQ4는 후반 작업(샌드박스 ffmpeg: 밝기·블룸 증가 → 화이트 페이드 → 하늘 이미지 → 타이틀)으로 만들 수 있습니다. 크레딧이 들지 않고, D2(불꽃 금지) 위반이나 다른 하늘이 생성될 위험도 없습니다.
- **필요하면:** 하늘 배경 정지 이미지 1장(gpt_image_2_5, 2.75cr)을 추가할 수 있습니다. 이 이미지도 hfgate raw spec을 거칩니다.

## 실행 순서 (A안)
1. 사용자가 SEQ1 v3를 화면으로 확인하고 OK하면 `accept SEQ1`
2. SEQ2.v2 approve → 사용자 확인 → 생성(120) → QA → 사용자 확인 → `accept SEQ2`
3. SEQ3.v2 approve → 사용자 확인 → 생성(120) → QA → 사용자 확인 → `accept SEQ3`
4. SEQ4 후반 합성 + 전체 조립(30fps 한 번 변환, 이음매 6프레임 디졸브, 오디오 크로스페이드) → 사용자 확인
5. 재시도가 필요하면 남은 156.5cr 안에서 1회. 반드시 G1~G5를 다시 거칩니다.
