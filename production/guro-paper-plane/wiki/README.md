# 구로 청소년축제 종이비행기 원테이크 — 제작 위키

> 이 위키와 `harness/` 폴더가 이 영상 작업의 **유일한 기준**입니다.
> 대화 기록이나 기억이 아니라, 여기 적힌 내용대로만 Higgsfield에 요청합니다.

## 왜 만들었나
- 지금까지 한 곳을 고치면 다른 곳이 깨지는 일이 반복됐습니다.
  - 예: SEQ1을 다시 만들었더니 이어지는 SEQ2·3과 복도 모습이 맞지 않게 됨
  - 예: 끝 이미지를 고정했더니 컷이 생김
- 그 과정에서 크레딧의 절반 이상을 썼습니다(1,600 중 남은 잔액 396.5).
- 남은 크레딧으로 **한 번에 끝내기 위한 장치**입니다.

## 3줄 원칙
1. **요청한 곳만 바꾼다.** 바뀐 항목이 사용자 요청 범위를 벗어나면 하네스가 요청을 막습니다(L9).
2. **보이는 장소는 전부 레퍼런스로 고정한다.** 문틈이나 창밖으로 잠깐 보이는 복도·운동장도 포함합니다(L2).
3. **사용자 확인 없이는 1크레딧도 쓰지 않는다.** Hook이 승인되지 않은 요청을 막습니다.

## 하네스 구성 (`harness/`)
- **`bible.json`**: 고정 사실을 모아 둔 파일입니다.
  - 장소·비행기 레퍼런스 ID
  - 고정 문구(lock)
  - 공통 금지어
  - 금지 단어와 그 근거가 되는 확정 결정
- **`state.json`**: 진행 상태를 기록합니다.
  - SEQ별 상태(candidate / accepted / stale)
  - 크레딧 잔액, 승인 기록, 사용 내역
- **`specs/*.json`**: SEQ별 요청 설계서입니다. 무엇을, 왜, 어디까지 바꾸는지 적습니다.
- **`hfgate.py`**: 설계서로 프롬프트를 만들고 검사·승인한 뒤, Hook으로 요청을 통제합니다.
- **`claude-settings.json`**: Claude Code Hook 설정 원본입니다. `.claude/settings.json`으로 복사해서 씁니다.
  - `.claude/`는 이 저장소에서 git 추적 대상이 아닙니다(gitignore).
  - 그래서 새 세션에서는 아래 명령으로 다시 설치합니다.
    ```
    mkdir -p .claude && cp production/guro-paper-plane/harness/claude-settings.json .claude/settings.json
    ```

## 크레딧이 나가는 흐름 (요약)
```
spec 작성 → hfgate lint(자동 검사 13종) → 사람 2차 검토(체크리스트)
→ hfgate approve(파라미터 해시 기록) → 사용자에게 비용·변경점 보고 → 사용자 OK
→ hfgate confirm → 요청 1회 (Hook이 해시 대조, 1회용)
→ 자동 QA(컷·이음매 검사) → 사용자 화면 확인 → accept (하위 SEQ는 자동으로 stale 처리)
```
