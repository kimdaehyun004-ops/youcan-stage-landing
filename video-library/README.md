# 영상 라이브러리

컴퓨터에 흩어져 있는 영상을 한 화면에 모아 보고, 그룹으로 정리한 다음
편집 프로그램(프리미어 프로, 다빈치 리졸브, 파이널컷, 캡컷 등)으로 **바로 끌어다 쓰는** 데스크톱 앱입니다.
Windows와 macOS에서 동작합니다.

## 주요 기능

| 기능 | 사용법 |
| --- | --- |
| 한눈에 보기 | 폴더를 추가하면 하위 폴더까지 모든 영상이 썸네일 격자로 정리됩니다 |
| 마우스 올려 미리보기 | 썸네일에 마우스를 올리면 재생되고, **좌우로 움직이면 그 위치로 탐색**합니다. 멈추면 그 지점부터 재생 |
| 크게 보기 | 더블클릭 또는 `Space` |
| 그룹 | 사이드바 `＋`로 만들고, 영상을 그룹 위로 끌어다 놓거나 우클릭 → 그룹에 추가. 한 영상이 여러 그룹에 들어갈 수 있습니다 |
| 편집할 때 꺼내 쓰기 | 카드를 **편집 프로그램 타임라인/미디어 창으로 끌어다 놓으면** 원본 파일이 그대로 들어갑니다 (복사본이 아님). 여러 개를 선택해 한 번에 끌 수도 있습니다 |
| 그룹째로 꺼내기 | 그룹 우클릭 → *그룹 영상 폴더로 복사* : 편집용 폴더에 모아서 넘기기 |
| 즐겨찾기 · 태그 | 선택 후 `F` 키, 우클릭 → 태그 편집. 검색창에서 이름·태그·그룹명으로 찾기 |
| 가져오기 | 탐색기/Finder에서 폴더나 영상 파일을 창으로 끌어다 놓기 |

### 단축키

`Ctrl/⌘+클릭` 여러 개 선택 · `Shift+클릭` 범위 선택 · `Ctrl/⌘+A` 전체 선택 · `Space` 크게 보기 ·
`F` 즐겨찾기 · `Delete` 현재 그룹에서 빼기 · `Ctrl/⌘+F` 검색 · `F5` 새로고침 · `Esc` 선택 해제

### 코덱 지원

- MP4(H.264), WebM, 일반 MOV 등은 앱 안에서 바로 재생·미리보기됩니다.
- 10bit HEVC, 4:2:2 카메라 원본, ProRes, AVI, MXF 등 앱 내장 플레이어가 못 읽는 코덱은 함께 들어 있는 ffmpeg로
  **360p 재생용 미리보기 사본**을 자동으로 만들어, 마우스를 올리거나 `Space`를 누르면 앱 안에서 바로 재생합니다.
  사본이 준비되는 동안(카드 오른쪽 위에 진행률 표시)은 프레임 10장짜리 필름스트립으로 넘겨 볼 수 있고,
  화면에 보이는 영상·마우스를 올린 영상부터 먼저 변환합니다.
- 사본은 데이터 폴더의 `thumbs\` 에 저장되며(1시간 영상 기준 약 150MB 이하), 원본 파일과 편집 프로그램으로 끌어다 놓는 파일은 항상 원본입니다.

## 설치

### 방법 1 — 설치 파일 받기 (권장)

GitHub 저장소의 **Actions → "영상 라이브러리 빌드"** 에서 가장 최근 실행을 열고
아래쪽 *Artifacts* 에서 받습니다.

- `video-library-Windows` : `VideoLibrary-Setup-1.0.0.exe`(설치형)와 `VideoLibrary-Portable-1.0.0.exe`(설치 없이 실행)
- `video-library-macOS` : `.dmg`

코드 서명이 되어 있지 않아 처음 실행할 때 경고가 뜰 수 있습니다.
Windows는 *추가 정보 → 실행*, macOS는 앱을 우클릭 → *열기* 를 누르면 됩니다.

### 방법 2 — 직접 실행 / 빌드

[Node.js](https://nodejs.org) 20 이상이 필요합니다.

```bash
cd video-library
npm install
npm start          # 바로 실행
npm run dist:win   # Windows 설치 파일 만들기 (dist 폴더)
npm run dist:mac   # macOS dmg 만들기 (Mac에서)
```

## 데이터 저장 위치

그룹·태그·즐겨찾기와 썸네일은 영상 파일을 건드리지 않고 아래 폴더에만 저장됩니다.

- Windows: `%APPDATA%\영상 라이브러리\` (`library.json`, `thumbs\`)
- macOS: `~/Library/Application Support/영상 라이브러리/`

포터블 exe로 실행하면 exe 옆의 `영상 라이브러리 데이터\` 폴더에 저장되므로, 폴더째 옮기거나 백업하기 쉽습니다.

영상 파일을 옮기거나 이름을 바꾸면 그 영상의 그룹 정보는 연결이 끊어집니다.
